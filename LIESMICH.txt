GEMEINSAMER ÜBUNGSKATALOG (uebungen.json)
1. Nutzer legen unter Team eine eigene Übung an und tippen "Auf GitHub vorschlagen"
   (oder schicken den Code per WhatsApp).
2. Du öffnest den Vorschlag (GitHub > Issues), kopierst den Code "KU1:..."
   und fügst ihn in der App unter Team > Übungskatalog verwalten ein.
3. "uebungen.json" herunterladen und im Repo die alte Datei ersetzen.
   Beim nächsten Öffnen haben alle die neuen Übungen.
Wichtig: Issues müssen im Repo aktiviert sein (Settings > General > Features > Issues).
